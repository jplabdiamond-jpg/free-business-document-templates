# Contributing

Thanks for helping improve these templates!

## Ways to help
- Fix a typo, unclear wording, or a broken link.
- Add a template for another document type (packing slip, pro forma invoice, timesheet, expense report, work order, donation receipt…).
- Add a country-specific tax note to [docs/tax-notes.md](docs/tax-notes.md).
- Improve the HTML template's print styling.

## How to submit
1. Fork the repository and create a branch.
2. Keep templates plain and portable — Markdown, HTML or CSV, with `{{ placeholders }}` for the parts a user fills in.
3. Don't include real business, customer, or payment data in examples. Use obvious placeholders only.
4. Open a pull request describing what you changed.

## Style
- Placeholders use double curly braces: `{{ like_this }}`.
- Keep wording neutral and country-agnostic unless the file is explicitly country-specific.
